# Farsights.ai beta site

Working beta-signup site for Farsights.ai and CAI.

This repo is intentionally separate from `farsights-stealth-site` so the current production placeholder can remain untouched while the beta experience is developed.

## Preview locally

Open `index.html` directly, or serve the folder with any static web server.

## Current status

- Static front end only
- Beta form is a prototype interaction and does not yet persist submissions
- Existing Farsights tree artwork is referenced from the current public site/repository during design iteration
- Production form handling, privacy copy, analytics, and deployment configuration are still to be finalized
